# Eonic Notes

Never have hierarchical notes been easier to visualise (I think)! This not is made to visualise notes in an geological timeline, but I'm sure crearive people will be able to use it for other purposes as well.

## Usage

This plugin is based on YAML properties of notes to handle the relevant data. To make the creation of notes easier, the sidebar button creates notes with the needed props for you, according to what you set up in the settings. Changing the settings afterwards will not influence existing notes however, to allow for a more flexible usage within your vault.

When you have your notes done, all left to do is to place a code block identified with 'eonic'.

There are several options to personalise the view:

- 'order'; value: 'desc' or 'asc'; default 'asc'
- 'tag'; value: name of the tag you want to filter for
- 'properties': value: array or list of the secondary columns of props to display, leave undevined to show all or set to '[]' to show none.
